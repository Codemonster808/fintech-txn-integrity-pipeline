# Security Policy

This is a portfolio/demo project. It runs entirely against local emulated AWS
infrastructure (MiniStack) and is not intended for production deployment or
to handle real transaction data, real credentials, or real customer PII.

## Reporting a vulnerability

If you find a security issue, please open a GitHub Issue on this repository
describing it. There is no SLA for response or remediation — this is
maintained on a best-effort basis as a personal portfolio project.
